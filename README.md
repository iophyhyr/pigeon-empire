# PIGEON EMPIRE

Браузерная игра на **Phaser 4** + **Vite**. Текущий статус — первый игровой прототип
с экономикой: городская крыша, голубь Pepper, крошки, пассивный доход и магазин
с первой коллекцией из семи голубей.

## Требования

- Node.js 20.19+ или 22.12+ (проверено на 22.22.3)
- npm 10+

## Команды

```bash
npm install      # установка зависимостей
npm run dev      # dev-сервер: http://localhost:5173
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр собранной версии
```

## Что уже есть

- Игровое поле 1280×720, FIT-масштабирование с сохранением пропорций и центрированием.
- Фон: небо, солнце, облака, два ряда зданий, крыша с парапетом и плиткой.
- Главный герой — Pepper, PNG-спрайт `public/assets/characters/pepper/pepper.png`
  (прозрачность сохранена, масштаб только пропорциональный). В ожидании плавно
  покачивается и «дышит» масштабом, при нажатии подпрыгивает и слегка сжимается.
- Валюта: крошки. Клик/тап по Pepper приносит крошки (базово 1), число за клик
  отображается в HUD и меняется улучшениями; всплывающий «+N», пульс счётчика.
- Пассивный доход начисляется раз в секунду и отображается в HUD. Сначала
  считается база от купленных голубей, затем применяются бонусы улучшений
  (все сразу, без промежуточных округлений).
- Магазин: окно «МАГАЗИН» с вкладками «ГОЛУБИ» и «УЛУЧШЕНИЯ», общая прокрутка
  внутри списка. Вкладка голубей — все семь первой коллекции:
  разведчик (25, +1/сек), курьер (100, +3/сек), работяга (250, +7/сек),
  торговец (600, +15/сек), учёный (1500, +35/сек), инженер (3500, +80/сек),
  охранник (8000, +180/сек). В карточке есть описание, цена, доход, счётчик
  покупок и кнопка. Каждый тип покупается один раз; после покупки кнопка
  показывает «КУПЛЕНО», а при нехватке крошек — понятное сообщение.
- Улучшения (вкладка «УЛУЧШЕНИЯ»): «Большой кусок хлеба» (+1 за клик, старт 100,
  максимум 10 уровней, рост цены ×1.5), «Вкусная приманка» (+2 за клик, старт 500,
  максимум 5, рост ×1.75), «Уютное гнездо» (+10% дохода за уровень, старт 1000,
  максимум 10, рост ×1.6) и «Крыша получше» (+25% дохода, 5000, один раз).
  Карточки показывают уровень, цену следующего уровня и недостаток крошек;
  завершённые — «МАКС.» или «КУПЛЕНО». Эффект применяется мгновенно.
- Достижения: 12 целей на сбор крошек, голубей, доход, силу клика и покупку
  улучшения «Крыша получше». У каждого есть описание, награда, шкала прогресса
  и статус; выполненные карточки выделены зелёным. Окно «ДОСТИЖЕНИЯ» открывается
  отдельной кнопкой HUD, показывает счётчик `X / 12`, прокручивается колесом
  или перетаскиванием и закрывается «✕», кликом вне окна или по Esc.
- Уведомления о достижениях появляются по очереди над HUD, поэтому несколько
  выполнений подряд не перекрывают экран. Награды начисляются один раз.
- Купленные голуби появляются на крыше сразу, каждый со своим PNG. Композиция
  пересчитывается при покупке и изменении размера окна: голуби симметрично
  заполняют ряды вокруг Pepper, не накладываются и не выходят за экран,
  дышат синхронно и легко покачиваются.
- PNG `worker.png` и `guard.png` не содержат альфа-канал. Их почти чёрный фон
  удаляется только в памяти при загрузке; исходные файлы остаются без изменений.
- Сохранение: крошки, купленные голуби, уровни улучшений, суммарно заработанные
  крошки и полученные достижения хранятся в LocalStorage под ключом
  `pigeon-empire.save.v1` (версия 4). Старые сохранения переносятся без сброса:
  новые поля начинаются с нуля, награды задним числом не начисляются.
  Повреждённые, отрицательные и NaN-значения безопасно нормализуются, а доход
  и сила клика из сохранения никогда не используются как источник истины.
- Управление: мышь и тач (Phaser pointer events, до 3 одновременных касаний).
  Магазин и окно достижений закрываются кнопкой «✕», кликом вне окна или по Esc;
  списки прокручиваются колесом или перетаскиванием. Содержимое списков обрезается
  маской по области прокрутки: в WebGL — Mask filter Phaser 4, в Canvas —
  GeometryMask. Маска и максимальная прокрутка пересчитываются при resize,
  а при уничтожении панели удаляются вместе с фильтром.

## Структура

```
index.html              # HTML-точка входа, контейнер #game
vite.config.js          # конфиг Vite (base, alias @ -> src, dev-сервер, сборка)
public/                 # статика, копируется в dist как есть
  assets/characters/    # PNG Pepper и семи покупаемых голубей (по папке на тип)
src/
  main.js               # создание экземпляра Phaser.Game
  game/
    config.js           # конфигурация Phaser
    constants.js        # размеры игры, ключи сцен, слои и текстуры
    palette.js          # цвета и шрифты в одном месте
    pigeons.js          # каталог голубей (цена, доход, описание, текстура)
    upgrades.js         # каталог улучшений и чистые формулы бонусов
    format.js           # общее форматирование чисел (дробный доход)
    achievements.js     # каталог достижений и чистые функции прогресса
    economy.js          # крошки, голуби, улучшения, достижения, LocalStorage
  scenes/
    BootScene.js        # техническая инициализация
    PreloadScene.js     # единственное место загрузки и подготовки ассетов
    GameScene.js        # игровой экран: фон, голуби, HUD, экономика
  objects/
    Pepper.js           # персонаж: спрайт, idle-анимация, подпрыгивание, хитбокс
    RoofPigeon.js       # покупаемый голубь на крыше со своей текстурой
    PigeonFlock.js      # синхронизация крыши с купленными голубями
    ScoutPigeon.js      # обратная совместимость: разведчик как частный случай
  ui/
    Hud.js              # верхний интерфейс и тост
    ShopPanel.js        # вкладки «Голуби/Улучшения» с прокруткой списка
    AchievementsPanel.js # окно достижений со шкалами и прокруткой
    AchievementToast.js # очередь мультяшных уведомлений о достижениях
    createButton.js     # переиспользуемая кнопка
  world/
    Backdrop.js         # небо, облака, город, крыша
  styles/main.css       # стили страницы и canvas
```

## Правила проекта

- Внешние изображения используются только для персонажей (`public/assets/characters/…`),
  фон, крыша и HUD по-прежнему рисуются примитивами Phaser Graphics.
- Ассеты грузятся только в `PreloadScene`; ключи текстур — в `TEXTURES` (`src/game/constants.js`),
  данные покупок — в `PIGEON_CATALOG` (`src/game/pigeons.js`).
- Экономика живёт только в `src/game/economy.js`; доход не хранится как источник истины
  и всегда пересчитывается из каталога и купленных типов.
- Ключи сцен, размеры и слои — в `src/game/constants.js`, цвета — в `src/game/palette.js`.
- Импорты внутри `src` можно писать через алиас `@` (например `@/game/constants.js`).
- Новая сцена = новый файл в `src/scenes/` + регистрация в `src/game/config.js`.
